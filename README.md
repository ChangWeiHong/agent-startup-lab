# Agent Startup Lab — Solo Venture OS

A GitHub-first, evidence-driven operating system for a solo entrepreneur.

**Operating principle:** validate willingness to pay before committing to product engineering. Research 3–5 opportunities at low cost, build deeply only when evidence justifies it.

This repository is the **shared source of truth** for both autonomous agents and local/cloud coding agents. They may execute work differently but share business policies, skills, work contracts, experiments, and decisions.

> Initial repository bootstrap. The complete V2 starter kit is proposed separately in a pull request for review.

No real customer data, API secrets, or ad account credentials should be committed to this public repository.
