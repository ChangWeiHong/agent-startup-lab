# advertising-experiment

**Use when:** Propose, measure and learn from capped acquisition tests

## Inputs
- Offer, segment, tracking plan and estimated economics
- Current platform rules and location
- Human-approved spend cap if launching

## Steps
1. Choose channel using advertising knowledge SOP
2. Draft one-variable creative variants with named IDs
3. Define attributable visit→paid funnel and budget/stops
4. Do not activate any campaign without explicit authorization
5. Analyze paying customers, refunds and cohort quality

## Outputs / acceptance
- Creative register, tracked experiment record and decision
- Actual vs estimated spend and attribution limitations
- Approval request if campaign creation or adjustment is proposed

## Gates
Read [work contract](../../../contracts/work-item.md) and [evidence](../../../contracts/evidence.md). Never claim fabricated verification, spend funds, contact customers, deploy or manipulate private data without explicit authorization. Return GitHub links when supported; otherwise structured handoff.
