# opportunity-discovery

**Use when:** Find testable narrow product opportunities

## Inputs
- Target geography/audience and available distribution
- Goal/constraints from strategy
- Existing Opportunity issues to avoid duplication

## Steps
1. Find observed pain and substitute products; record citations and dates
2. Write user + friction trigger + current workaround + possible payer
3. Check reachability, recurring value, competitors and major risks
4. Propose the cheapest falsifying experiment

## Outputs / acceptance
- Linked Opportunity issue or work package
- 3–5 concise candidate summaries or fewer if evidence is weak
- Unknowns and explicit next action

## Gates
Read [work contract](../../../contracts/work-item.md) and [evidence](../../../contracts/evidence.md). Never claim fabricated verification, spend funds, contact customers, deploy or manipulate private data without explicit authorization. Return GitHub links when supported; otherwise structured handoff.
