# Portable agent skills

Each folder contains a focused `SKILL.md` with intent, inputs, workflow, outputs and gates. These are **human-readable skill contracts**, not guaranteed to be auto-discovered by every agent provider. For platforms without local skill discovery, supply the path and contents explicitly.

- [Opportunity discovery](opportunity-discovery/SKILL.md)
- [Market validation](market-validation/SKILL.md)
- [Advertising experiment](advertising-experiment/SKILL.md)
- [Business planning](business-planning/SKILL.md)
- [PRD engineering](prd-engineering/SKILL.md)
- [Venture retrospective](venture-retrospective/SKILL.md)

All skills inherit [AGENTS.md](../../AGENTS.md) and [work contract](../../contracts/work-item.md). A skill cannot authorize spend or production changes.
