# venture-retrospective

**Use when:** Turn experiment outcomes into reusable decisions

## Inputs
- Experiment's original hypothesis and predeclared gates
- Actual evidence/metrics and spend
- Customer, support and engineering signals if present

## Steps
1. Identify what genuinely happened vs expected
2. Separate acquisition problems from poor activation or retention
3. Capture supported insights, surprise and uncertainty
4. Propose scale, iterate, pause or kill with smallest next test

## Outputs / acceptance
- Decision record with evidence URLs
- Reusable knowledge update proposal (PR) not duplicate status

## Gates
Read [work contract](../../../contracts/work-item.md) and [evidence](../../../contracts/evidence.md). Never claim fabricated verification, spend funds, contact customers, deploy or manipulate private data without explicit authorization. Return GitHub links when supported; otherwise structured handoff.
