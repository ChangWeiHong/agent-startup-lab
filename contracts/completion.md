# Completion and approval contract

## Definition of Done

- Linked work item and outputs exist in their correct canonical locations.
- Acceptance criteria checked with stated method; no invented test results.
- Evidence and assumptions are separately identified with source/date.
- For code: tests or manual verification recorded, PR reviewed, security implications documented.
- For ads/research: spend and attribution documented, metric denominators present and limits explained.
- Decision/next owner/action recorded; any blocker explicit.
- No new secrets or raw customer PII entered the public repo.

## Human approval always required

Activating/increasing ad spend; purchasing infrastructure; account and billing changes; contacting users as the owner; production deploy; destructive writes; disclosure of private data; modifying access rights.

Human approval for one named action **does not** authorize other external actions or future budget increases.

If unsure, generate a proposed plan and an approval request instead of acting.
