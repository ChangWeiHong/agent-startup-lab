# Venture lifecycle index

| Stage | Playbook | Exit artifact / question |
| --- | --- | --- |
| 01 | [Discover](discover.md) | traceable opportunity candidate |
| 02 | [Evaluate](evaluate.md) | priority and explicit falsifiable hypotheses |
| 03 | [Validate](validate.md) | observed willingness to pay or clear negative signal |
| 04 | [Plan](plan.md) | scoped lean plan and PRD only when justified |
| 05 | [Build](build.md) | tested MVP change under review |
| 06 | [Launch](launch.md) | safely accessible experience with analytics |
| 07 | [Operate](operate.md) | working support, monitoring, cost and retention loop |
| 08 | [Decide](decide.md) | decision record, next investment or stop |

The order is not rigid; learning may move a venture backwards. An experiment may be stopped before any code is written.

Every step follows [Work Contract](../contracts/work-item.md) and [Evidence](../contracts/evidence.md).
